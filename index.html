1BIOS Flashing (VGC)

⚠️ Valorant requires BIOS Flash. If you only play Fortnite, this step is optional but still recommended for the cleanest result.

Flashing clears leftover VGC (Valorant anti-cheat) traces and resets the platform keys in your BIOS. This is a required step for a clean permanent spoof on Valorant.

Before you begin

  • Know your exact motherboard model
  • Have a USB drive (8GB+) and a PC that still boots
  • Download the matching BIOS file from your board manufacturer
  • Back up any important data on the machine

Flashing steps

  1. Identify your board
    Check the model in MSINFO32 or on the board itself, then grab the correct BIOS from the manufacturer site.
  2. Prepare a USB
    Format a FAT32 USB drive and place the downloaded BIOS file at the root.
  3. Enter BIOS
    Restart and press the correct key (DEL / F2 / F10 depending on brand) to open BIOS.
  4. Launch the flash tool
    Use the built-in flashing utility (EZ Flash / Flashback / M-Flash) and select the file from the USB.
  5. Flash & wait
    Confirm, let the flash finish. Do not power off during flashing.

🔍 How do you check if your flash was successful?

The version & date should be changed, which can be found at your System Information.

⚠️ Critical: Never interrupt a BIOS flash. A failed flash can require recovery or a hardware programmer.

2BIOS Config

After flashing, configure the BIOS settings so the fresh firmware state persists and no leftover profiles remain.

  1. Load optimized defaults
    In BIOS, select "Load Optimized Defaults" then save & exit once.
  2. Disable Secure Boot (for now)
    Set Secure Boot to disabled — it will be re-enabled in the spoofing step if required.
  3. Check platform keys
    If your board offers "Clear PTT / Clear Secure Boot keys / Restore Factory Keys", run it to wipe signature data.
  4. Reboot
    Save and exit, letting the board reconfigure itself.

🟦 Normal reinstallation (Intel)

  1. Download Media Creation Tool
    Get it from the official Microsoft page and click "Download Now".
  2. Run as administrator
    Open the tool and select "Create installation media (USB flash drive)".
  3. Use recommended options
    Continue and let it write the USB. It should take a few minutes.
  4. SHIFT + Restart
    Hold SHIFT, click Restart, keep holding until the blue menu appears.
  5. Boot from the USB
    Choose "Use a device" and select your flash drive.
  6. Select Windows Pro
    Pick a Pro edition, then "I don't have a product key".
  7. Custom install
    Select "Custom: Install Windows only (advanced)".
  8. Open diskpart
    Press SHIFT + F10, type diskpart, then list disk.
  9. Clean your drives
    For each internal drive (NOT the USB): select disk X then clean.
  10. Refresh and install
    Close CMD, click Refresh, select the unallocated space, and install.
  11. Offline account
    Create an offline account and turn off all privacy settings.

🟥 RAID reinstallation (AMD)

⚠️ MAKE SURE TO REMEMBER YOUR DISK SERIALS. Take a photo of them on your phone. USE OUR SERIAL CHECKERS!

RAID / VMD setups hide the drive behind a controller, so the standard flow won't see it. Follow these steps carefully.

🌐 Note: Most modern systems auto-install Ethernet drivers after reinstall. If you lose connection, download the network (LAN) drivers for your motherboard (e.g. "Asus B550 Network drivers") and save them on the USB as a precaution.
  1. Download the Media Creation Tool
    Go to Microsoft, click "Download Now".
  2. Run as administrator
    Open the tool and select "Create Installation media (USB flash drive)". Use all the recommended options and wait for it to finish.
  3. Save & exit the BIOS
    Make sure your USB is plugged into the PC, then save & exit BIOS.
  4. Windows setup loads
    Press Next. If asked for a product key, select "I don't have a product key".
  5. Select the OS
    Choose Windows 10 Pro, accept the TOS, press Next.
  6. Load driver
    At "Where do you want to install Windows?", click Load driver → Browse → navigate to the USB.
  7. Pick your RAID driver
    Select the folder dropdown, choose either NVMe_RAID or SATA_RAID → press Ok.
  8. Choose your driver
    Select the first option "AMD-RAID Bottom Device" driver → Next.
  9. Install
    Select the disk to install Windows on, press Next, and wait for it to finish.
⚠️ Make sure to follow these steps while and after reinstallation:
1. Make an offline account or a new Microsoft account. Don't log into your old one.
2. Do not log into OneDrive, GeForce Experience & Medal with the same account.
3. Install vc_redist.x64.exe to prevent any errors.

🧪 How to check if my RAID worked after reinstall

  1. Open Task Manager
    Click the Performance tab.
  2. Click "Disk 0 (C:)"
    It should say "AMD-RAID" on the top right.

4Verify MSINFO32

🖥️ Auto Motherboard Detection System

Our permanent spoofer uses a system called Auto Motherboard Detection to dynamically detect your motherboard model and apply the correct spoofing configuration.

✅ For this system to work properly, a fixed, correct, and uncorrupted msinfo32 is required. If msinfo32 is missing, corrupted, or inaccurate, spoofing may fail or result in reduced performance and increased detection risk.

How to check?

  1. Open MSINFO32
    Press Win + R, type msinfo32, and hit Enter.
  2. Under System Summary, look for
    - BaseBoard Manufacturer
    - BaseBoard Product
    - BaseBoard Version
  3. Cross-check with BIOS > EZ Mode
    To enter BIOS easily, open CMD as Administrator and run: shutdown /r /fw /t 0
⚠️ IMPORTANT
If any value in msinfo32 or BIOS does not match your original hardware, use our SMBIOS Fixer.
If you've ever used other spoofing tools (e.g. "bad/free perms") before ours, use our SMBIOS Fixer.

🖥️HP Spoof

💡 HP boards use a locked "manufacturer mode". This guide unlocks it so you can then spoof your serials normally.
  1. Plug in your USB (FAT-32)
    Make sure the USB is formatted as FAT-32.
  2. Open the spoofer → Custom Tab
    Go to the Custom tab and press HP Unlock.
  3. Enter BIOS (usually F9)
    Choose "Load File From EFI".
  4. Select your USB drive
  5. Select "bootx64.efi"
  6. Wait for the prompt
    It will show "Manufacturer mode to unlock mode" → click YES.
  7. Boots into Windows
    If Windows does not boot, change "Boot Priority #1" to "Windows Boot Manager".
